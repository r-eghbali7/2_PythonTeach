# مجموعه (Set) در پایتون

`Set` یا **مجموعه** یکی از ساختارهای داده در پایتون است که برای نگهداری مجموعه‌ای از عناصر **غیرتکراری و بدون ترتیب مشخص** استفاده می‌شود.

یکی از ویژگی‌های مهم `Set` این است که می‌توان عناصر جدیدی به آن اضافه کرد یا عناصر موجود را حذف کرد، اما نمی‌توان مقدار یک عنصر موجود را مستقیماً تغییر داد.

همچنین پایتون امکانات مختلفی برای انجام عملیات ریاضی روی مجموعه‌ها در اختیار ما قرار می‌دهد؛ عملیاتی مانند:

* اجتماع (Union)
* اشتراک (Intersection)
* تفاضل (Difference)

---

# 1. ویژگی‌های مجموعه (Set)

اعضای یک مجموعه در پایتون چند ویژگی مهم دارند:

1. **بدون ترتیب مشخص (Unordered)**
2. **غیرتکراری (Unique)**
3. **قابل تغییر بودن خود مجموعه (Mutable)**

اما عناصری که داخل `Set` قرار می‌گیرند باید از نوع **Hashable** باشند؛ به همین دلیل نمی‌توان مثلاً یک `list` را مستقیماً به عنوان عضو مجموعه قرار داد.

---

# 2. نامرتب بودن مجموعه (Unordered)

منظور از نامرتب بودن این است که نمی‌توانیم برای عناصر یک `Set` ترتیب مشخصی مانند لیست در نظر بگیریم.

برای مثال:

```python id="n7x6e2"
numbers = {10, 20, 30, 40}
```

برخلاف لیست:

```python id="8o8j4w"
numbers = [10, 20, 30, 40]
```

مجموعه دارای **اندیس (Index)** نیست.

بنابراین نمی‌توانیم به شکل زیر به یکی از عناصر آن دسترسی پیدا کنیم:

```python id="k9w8z3"
numbers[0]
```

این کد باعث ایجاد خطا می‌شود.

**نکته:** اگرچه در نسخه‌های مختلف پایتون ممکن است هنگام چاپ یک `set` ترتیب خاصی مشاهده شود، نباید روی این ترتیب حساب کنیم؛ `set` برای نگهداری داده‌های مرتب و دارای اندیس طراحی نشده است.

---

# 3. غیرتکراری بودن عناصر مجموعه

یکی از مهم‌ترین ویژگی‌های `Set` این است که عناصر تکراری را نگهداری نمی‌کند.

برای مثال:

```python id="e4f9m2"
numbers = {10, 20, 10, 30, 20, 40}

print(numbers)
```

مقادیر تکراری حذف می‌شوند و مجموعه فقط یک نمونه از هر مقدار را نگهداری می‌کند.

به همین دلیل، `Set` گزینه مناسبی برای حذف مقادیر تکراری از داده‌ها است.

مثال:

```python id="x8k3q1"
numbers = [10, 20, 10, 30, 20, 40]

unique_numbers = set(numbers)

print(unique_numbers)
```

در اینجا لیست به یک مجموعه تبدیل شده و مقادیر تکراری حذف می‌شوند.

---

# 4. قابل تغییر بودن Set

یک نکته مهم درباره `Set` وجود دارد:

> **خود Set قابل تغییر (Mutable) است، اما نمی‌توان مقدار یک عنصر موجود را مستقیماً تغییر داد.**

یعنی می‌توانیم:

* عنصر جدید اضافه کنیم.
* عنصر موجود را حذف کنیم.
* تمام عناصر مجموعه را پاک کنیم.

اما نمی‌توانیم مانند لیست بنویسیم:

```python id="n4v6p2"
numbers[0] = 100
```

زیرا `Set` اندیس ندارد.

برای تغییر یک مقدار، معمولاً ابتدا آن را حذف و سپس مقدار جدید را اضافه می‌کنیم.

```python id="f5s2q8"
numbers = {10, 20, 30}

numbers.remove(20)
numbers.add(25)

print(numbers)
```

---

# 5. ساخت مجموعه

برای ساخت یک مجموعه می‌توانیم از `{}` همراه با عناصر استفاده کنیم:

```python id="p6j2s9"
numbers = {10, 20, 30, 40}
```

همچنین می‌توانیم از تابع `set()` استفاده کنیم:

```python id="v8k3m1"
numbers = set([10, 20, 30, 40])
```

تابع `set()` می‌تواند یک **Iterable** را به عنوان ورودی دریافت کند و عناصر آن را به یک مجموعه تبدیل کند.

برای مثال:

```python id="z2r7c4"
numbers = set([10, 20, 10, 30])
```

خروجی مجموعه شامل مقادیر غیرتکراری خواهد بود.

---

# 6. ساخت مجموعه خالی

برای ایجاد یک مجموعه خالی باید از `set()` استفاده کنیم:

```python id="b7m4q2"
numbers = set()
```

**نکته مهم:**

نوشتن:

```python id="p8n5s3"
numbers = {}
```

یک `Set` خالی ایجاد نمی‌کند؛ بلکه یک **دیکشنری خالی (Dictionary)** ایجاد می‌کند.

بنابراین:

```python id="k3q9v1"
set()
```

برای ساخت مجموعه خالی استفاده می‌شود.

---

# 7. دسترسی به اعضای Set

از آنجا که `Set` دارای اندیس نیست، نمی‌توانیم با استفاده از `[]` به یک عنصر مشخص دسترسی پیدا کنیم.

این کد صحیح نیست:

```python id="c5t8x2"
numbers = {10, 20, 30}

print(numbers[0])
```

اگر بخواهیم تمام عناصر مجموعه را مشاهده کنیم، می‌توانیم از حلقه `for` استفاده کنیم:

```python id="r2m7k4"
numbers = {10, 20, 30}

for number in numbers:
    print(number)
```

---

# 8. به دست آوردن تعداد عناصر با `len()`

برای محاسبه تعداد عناصر موجود در یک مجموعه از تابع `len()` استفاده می‌کنیم.

```python id="v6q2m8"
numbers = {10, 20, 30, 40}

print(len(numbers))
```

خروجی:

```text id="j4k8n2"
4
```

---

# 9. بررسی وجود یک مقدار با `in`

برای بررسی اینکه یک مقدار در مجموعه وجود دارد یا خیر، از عملگر `in` استفاده می‌کنیم.

```python id="m9r3x7"
numbers = {10, 20, 30, 40}

print(20 in numbers)
```

خروجی:

```text id="a2p7v5"
True
```

اگر مقدار وجود نداشته باشد:

```python id="q8n4c6"
print(50 in numbers)
```

خروجی:

```text id="w5m2r9"
False
```

همچنین می‌توانیم از `not in` استفاده کنیم:

```python id="e7k3p1"
print(50 not in numbers)
```

خروجی:

```text id="u4q8m6"
True
```

---

# 10. افزودن عضو جدید با `add()`

برای اضافه کردن یک عنصر جدید به مجموعه از متد `add()` استفاده می‌کنیم.

```python id="s6v2k9"
numbers = {10, 20, 30}

numbers.add(40)

print(numbers)
```

اکنون `40` به مجموعه اضافه شده است.

اگر مقداری که اضافه می‌کنیم از قبل در مجموعه وجود داشته باشد، مقدار جدیدی اضافه نمی‌شود:

```python id="x3m8q5"
numbers.add(20)
```

چون `20` از قبل وجود دارد، مجموعه تغییری نمی‌کند.

---

# 11. افزودن چند عنصر با `update()`

برای اضافه کردن چند عنصر به صورت هم‌زمان می‌توانیم از متد `update()` استفاده کنیم.

```python id="n5r7c2"
numbers = {10, 20}

numbers.update([30, 40, 50])

print(numbers)
```

خروجی شامل تمام عناصر خواهد بود:

```text id="h4q9m6"
{10, 20, 30, 40, 50}
```

`update()` می‌تواند یک `Iterable` مانند لیست، تاپل یا مجموعه را دریافت کند.

مثال:

```python id="k7p2s4"
numbers.update((60, 70))
```

---

# 12. حذف عنصر با `remove()`

برای حذف یک عنصر مشخص از مجموعه می‌توانیم از `remove()` استفاده کنیم.

```python id="q6m3v8"
numbers = {10, 20, 30, 40}

numbers.remove(30)

print(numbers)
```

در این مثال مقدار `30` حذف می‌شود.

**نکته مهم:** اگر مقدار مورد نظر در مجموعه وجود نداشته باشد، `remove()` خطای `KeyError` ایجاد می‌کند.

---

# 13. حذف عنصر با `discard()`

متد `discard()` نیز برای حذف یک عنصر از مجموعه استفاده می‌شود.

```python id="t8n5r2"
numbers = {10, 20, 30}

numbers.discard(20)
```

تفاوت `discard()` و `remove()` زمانی مشخص می‌شود که عنصر مورد نظر در مجموعه وجود نداشته باشد.

اگر عنصر وجود نداشته باشد:

```python id="y4p7m1"
numbers.discard(50)
```

هیچ خطایی ایجاد نمی‌شود.

اما:

```python id="z3q8v6"
numbers.remove(50)
```

باعث ایجاد خطا می‌شود.

بنابراین:

| متد         | اگر عنصر وجود داشته باشد | اگر عنصر وجود نداشته باشد |
| ----------- | ------------------------ | ------------------------- |
| `remove()`  | حذف می‌شود               | `KeyError`                |
| `discard()` | حذف می‌شود               | هیچ اتفاقی نمی‌افتد       |

---

# 14. اجتماع دو مجموعه (Union)

**اجتماع (Union)** دو مجموعه شامل تمام عناصری است که در مجموعه اول یا مجموعه دوم وجود دارند.

برای انجام اجتماع می‌توانیم از عملگر `|` استفاده کنیم.

```python id="b9k4m7"
set1 = {1, 2, 3}
set2 = {3, 4, 5}

result = set1 | set2

print(result)
```

خروجی:

```text id="c6p2x8"
{1, 2, 3, 4, 5}
```

همچنین می‌توانیم از متد `union()` استفاده کنیم:

```python id="f7m3q9"
result = set1.union(set2)
```

---

# 15. اشتراک دو مجموعه (Intersection)

**اشتراک (Intersection)** شامل عناصری است که در هر دو مجموعه وجود دارند.

برای انجام اشتراک از عملگر `&` استفاده می‌کنیم.

```python id="r5n8v2"
set1 = {1, 2, 3}
set2 = {2, 3, 4}

result = set1 & set2

print(result)
```

خروجی:

```text id="m6q4p1"
{2, 3}
```

همچنین می‌توانیم از متد `intersection()` استفاده کنیم:

```python id="x8c3k7"
result = set1.intersection(set2)
```

---

# 16. تفاضل دو مجموعه (Difference)

**تفاضل (Difference)** شامل عناصری از مجموعه اول است که در مجموعه دوم وجود ندارند.

برای انجام تفاضل از عملگر `-` استفاده می‌کنیم.

```python id="n2v6r8"
set1 = {1, 2, 3}
set2 = {2, 3, 4}

result = set1 - set2

print(result)
```

خروجی:

```text id="q7m4c2"
{1}
```

همچنین می‌توانیم از متد `difference()` استفاده کنیم:

```python id="s9k3p6"
result = set1.difference(set2)
```

**نکته:** ترتیب مجموعه‌ها در تفاضل مهم است.

```python id="v5m8q1"
set1 - set2
```

با:

```python id="k2r7n4"
set2 - set1
```

نتیجه یکسانی ندارد.

---

# جمع‌بندی

`Set` برای زمانی مناسب است که بخواهیم مجموعه‌ای از داده‌های **غیرتکراری و بدون ترتیب مشخص** داشته باشیم.

مهم‌ترین عملیات و متدهای `Set` عبارت‌اند از:

| عملیات                     | روش                     |
| -------------------------- | ----------------------- |
| ساخت مجموعه                | `{1, 2, 3}`             |
| ساخت مجموعه خالی           | `set()`                 |
| تبدیل Iterable به Set      | `set()`                 |
| تعداد عناصر                | `len()`                 |
| بررسی وجود عنصر            | `in`                    |
| افزودن یک عنصر             | `add()`                 |
| افزودن چند عنصر            | `update()`              |
| حذف با خطا در صورت نبودن   | `remove()`              |
| حذف بدون خطا در صورت نبودن | `discard()`             |
| اجتماع                     | `\|` یا `union()`       |
| اشتراک                     | `&` یا `intersection()` |
| تفاضل                      | `-` یا `difference()`   |

### نکات مهمی که باید به خاطر بسپاریم

1. `Set` **ترتیب و اندیس قابل اتکا ندارد**.
2. عناصر تکراری در `Set` نگهداری نمی‌شوند.
3. خود `Set` **Mutable** است؛ یعنی می‌توان عناصر آن را اضافه یا حذف کرد.
4. مقدار یک عنصر موجود را نمی‌توان مستقیماً مانند لیست تغییر داد.
5. عناصر `Set` باید **Hashable** باشند.
6. برای ایجاد `Set` خالی باید از `set()` استفاده کنیم، نه `{}`.
7. برای عملیات بین مجموعه‌ها می‌توان از عملگرهای `|`، `&` و `-` استفاده کرد.
