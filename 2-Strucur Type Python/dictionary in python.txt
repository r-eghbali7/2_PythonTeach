# دیکشنری (Dictionary) در پایتون

دیکشنری یکی از ساختارهای داده پرکاربرد در پایتون است که برای **ذخیره و مدیریت اطلاعات به صورت کلید و مقدار (Key-Value)** استفاده می‌شود.

## 1. دیکشنری چیست؟

معمولاً از دیکشنری پایتون در مواقعی استفاده می‌کنیم که نیاز داریم هر مقدار را با استفاده از یک **کلید (Key)** شناسایی کنیم.

مقدارهای یک دیکشنری می‌توانند از هر نوع داده‌ای باشند؛ برای مثال:

* رشته متنی (`str`)
* عدد (`int`, `float`)
* لیست (`list`)
* تاپل (`tuple`)
* شیء (Object)
* حتی یک دیکشنری دیگر

برای مثال:

```python
person = {
    "name": "Ali",
    "age": 25,
    "city": "Tehran"
}
```

در این مثال:

* `"name"` یک کلید است و `"Ali"` مقدار آن است.
* `"age"` یک کلید است و `25` مقدار آن است.
* `"city"` یک کلید است و `"Tehran"` مقدار آن است.

---

## 2. اعضای دیکشنری

معمولاً اعضای یک دیکشنری با یکدیگر مرتبط هستند و هر کدام می‌توانند یک ویژگی یا مشخصه از یک موضوع را نشان دهند.

برای مثال، اگر بخواهیم اطلاعات یک شخص را ذخیره کنیم:

```python
person = {
    "name": "Ali",
    "age": 25,
    "job": "Programmer",
    "city": "Tehran"
}
```

در اینجا اطلاعات مختلف مربوط به یک شخص در قالب **کلید و مقدار** ذخیره شده‌اند.

---

## 3. نحوه تعریف دیکشنری

دیکشنری با علامت `{` شروع و با علامت `}` پایان می‌یابد.

هر عضو دیکشنری از یک **کلید و مقدار** تشکیل شده است که بین آن‌ها از علامت `:` استفاده می‌کنیم.

اعضای مختلف دیکشنری نیز با علامت `,` از یکدیگر جدا می‌شوند.

ساختار کلی:

```python
dictionary = {
    key: value,
    key: value,
    key: value
}
```

مثال:

```python
person = {
    "name": "Ali",
    "age": 25,
    "city": "Tehran"
}
```

---

## 4. ساخت دیکشنری با تابع `dict()`

راه دیگر برای ساخت دیکشنری، استفاده از تابع `dict()` است.

برای مثال:

```python
person = dict(
    name="Ali",
    age=25,
    city="Tehran"
)
```

در این روش، نام پارامترها به عنوان کلید و مقادیر آن‌ها به عنوان مقدار دیکشنری در نظر گرفته می‌شوند.

همچنین می‌توان یک دیکشنری خالی ایجاد کرد:

```python
person = dict()
```

یا:

```python
person = {}
```

---

# 5. دسترسی به مقادیر دیکشنری

برای دسترسی به مقدار یک کلید در دیکشنری، دو روش متداول وجود دارد.

## روش اول: استفاده از `[]`

این روش شبیه دسترسی به عناصر لیست است؛ با این تفاوت که در لیست از **اندیس عددی** استفاده می‌کنیم، اما در دیکشنری از **کلید** استفاده می‌شود.

```python
person = {
    "name": "Ali",
    "age": 25
}

print(person["name"])
```

خروجی:

```text
Ali
```

همچنین:

```python
print(person["age"])
```

خروجی:

```text
25
```

**نکته:** اگر کلیدی که جستجو می‌کنیم در دیکشنری وجود نداشته باشد، استفاده از این روش باعث ایجاد خطای `KeyError` می‌شود.

---

## روش دوم: استفاده از `get()`

روش دیگر، استفاده از متد `get()` است.

```python
person = {
    "name": "Ali",
    "age": 25
}

print(person.get("name"))
```

خروجی:

```text
Ali
```

مزیت `get()` این است که اگر کلید وجود نداشته باشد، به صورت پیش‌فرض `None` برمی‌گرداند و خطا ایجاد نمی‌کند.

```python
print(person.get("job"))
```

خروجی:

```text
None
```

همچنین می‌توانیم یک مقدار پیش‌فرض مشخص کنیم:

```python
print(person.get("job", "Unknown"))
```

خروجی:

```text
Unknown
```

---

# 6. تغییر مقدار یک کلید در دیکشنری

برای تغییر مقدار یک کلید، کافی است کلید مورد نظر را داخل `[]` قرار داده و مقدار جدید را به آن اختصاص دهیم.

```python
person = {
    "name": "Ali",
    "age": 25
}

person["age"] = 30

print(person)
```

خروجی:

```text
{'name': 'Ali', 'age': 30}
```

در این مثال مقدار کلید `"age"` از `25` به `30` تغییر کرده است.

---

# 7. افزودن عنصر جدید به دیکشنری

برای اضافه کردن یک عضو جدید نیز از همان روش استفاده می‌کنیم.

تفاوت این است که این بار کلیدی که استفاده می‌کنیم، از قبل در دیکشنری وجود ندارد.

```python
person = {
    "name": "Ali",
    "age": 25
}

person["city"] = "Tehran"

print(person)
```

خروجی:

```text
{'name': 'Ali', 'age': 25, 'city': 'Tehran'}
```

بنابراین:

* اگر کلید وجود داشته باشد → مقدار آن **به‌روزرسانی** می‌شود.
* اگر کلید وجود نداشته باشد → یک **عضو جدید** به دیکشنری اضافه می‌شود.

---

# 8. حذف عناصر از دیکشنری

برای حذف یک عضو از دیکشنری، چند روش وجود دارد.

## روش اول: استفاده از `del`

با استفاده از دستور `del` می‌توان یک کلید و مقدار مربوط به آن را حذف کرد.

```python
person = {
    "name": "Ali",
    "age": 25,
    "city": "Tehran"
}

del person["city"]

print(person)
```

خروجی:

```text
{'name': 'Ali', 'age': 25}
```

---

## روش دوم: استفاده از `pop()`

روش دیگر، استفاده از متد `pop()` است.

```python
person = {
    "name": "Ali",
    "age": 25,
    "city": "Tehran"
}

person.pop("city")

print(person)
```

خروجی:

```text
{'name': 'Ali', 'age': 25}
```

تفاوت مهم این است که `pop()` علاوه بر حذف کردن عضو، **مقدار حذف‌شده را نیز برمی‌گرداند**.

مثال:

```python
age = person.pop("age")

print(age)
```

---

# 9. حذف کل دیکشنری با `del`

اگر بخواهیم خود دیکشنری را به طور کامل حذف کنیم، می‌توانیم از `del` استفاده کنیم.

```python
person = {
    "name": "Ali",
    "age": 25
}

del person
```

بعد از اجرای این دستور، متغیر `person` دیگر وجود نخواهد داشت.

---

# 10. حذف تمام عناصر دیکشنری با `clear()`

اگر بخواهیم **محتویات دیکشنری را حذف کنیم ولی خود دیکشنری باقی بماند**، از `clear()` استفاده می‌کنیم.

```python
person = {
    "name": "Ali",
    "age": 25
}

person.clear()

print(person)
```

خروجی:

```text
{}
```

بنابراین تفاوت این دو روش مهم است:

```python
del person
```

دیکشنری را به طور کامل حذف می‌کند.

اما:

```python
person.clear()
```

فقط عناصر داخل دیکشنری را حذف می‌کند و یک دیکشنری خالی باقی می‌گذارد.

---

# 11. قوانین کلیدهای دیکشنری

کلیدهای دیکشنری باید دارای دو ویژگی مهم باشند:

### 1. کلیدها باید یکتا باشند

در یک دیکشنری نمی‌توان دو کلید یکسان داشت.

برای مثال:

```python
person = {
    "name": "Ali",
    "name": "Reza"
}
```

در این حالت کلید `"name"` دوبار نوشته شده است و مقدار نهایی آن `"Reza"` خواهد بود.

```python
print(person)
```

خروجی:

```text
{'name': 'Reza'}
```

بنابراین بهتر است کلیدهای دیکشنری **منحصربه‌فرد (Unique)** باشند.

### 2. کلیدها باید تغییرناپذیر (Immutable) باشند

کلیدهای دیکشنری باید از نوع داده‌ای باشند که قابلیت تغییر نداشته باشد.

برای مثال، موارد زیر می‌توانند کلید دیکشنری باشند:

```python
"name"
10
3.14
(1, 2)
```

اما `list` نمی‌تواند به عنوان کلید استفاده شود:

```python
my_dict = {
    [1, 2]: "Hello"
}
```

این کد باعث ایجاد خطا می‌شود، زیرا لیست قابل تغییر (Mutable) است.

**نکته:** مقادیر دیکشنری چنین محدودیتی ندارند و می‌توانند از انواع مختلف داده، حتی لیست و دیکشنری، باشند.

---

# 12. کپی کردن دیکشنری با `copy()`

برای ایجاد یک کپی از دیکشنری می‌توانیم از متد `copy()` استفاده کنیم.

```python
person = {
    "name": "Ali",
    "age": 25
}

new_person = person.copy()

print(new_person)
```

خروجی:

```text
{'name': 'Ali', 'age': 25}
```

در این حالت یک کپی جداگانه از دیکشنری ایجاد می‌شود.

برای مثال:

```python
new_person["age"] = 30

print(person)
print(new_person)
```

خروجی:

```text
{'name': 'Ali', 'age': 25}
{'name': 'Ali', 'age': 30}
```

بنابراین تغییر مقدار در `new_person` باعث تغییر مقدار متناظر در `person` نمی‌شود.

---

## جمع‌بندی

دیکشنری یکی از مهم‌ترین ساختارهای داده در پایتون است که اطلاعات را به صورت **کلید و مقدار (Key-Value)** ذخیره می‌کند.

مهم‌ترین عملیات روی دیکشنری عبارت‌اند از:

| عملیات                    | روش                 |
| ------------------------- | ------------------- |
| ساخت دیکشنری              | `{}` یا `dict()`    |
| دسترسی به مقدار           | `dict[key]`         |
| دسترسی امن به مقدار       | `dict.get(key)`     |
| تغییر مقدار               | `dict[key] = value` |
| افزودن عضو                | `dict[key] = value` |
| حذف عضو                   | `del dict[key]`     |
| حذف عضو و دریافت مقدار آن | `dict.pop(key)`     |
| حذف تمام عناصر            | `dict.clear()`      |
| حذف خود دیکشنری           | `del dict`          |
| کپی کردن                  | `dict.copy()`       |

به طور خلاصه، مهم‌ترین نکته درباره دیکشنری این است که برخلاف لیست که اطلاعات را بر اساس **اندیس** پیدا می‌کنیم، در دیکشنری اطلاعات را بر اساس **کلید** پیدا می‌کنیم.
