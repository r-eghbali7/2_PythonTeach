# تاپل (Tuple) در پایتون

`Tuple` یا **تاپل** یکی از ساختارهای داده در پایتون است که برای ذخیره چند مقدار در یک متغیر استفاده می‌شود.

تاپل شباهت زیادی به `List` دارد، با این تفاوت مهم که **تاپل تغییرناپذیر (Immutable)** است؛ یعنی بعد از ایجاد آن نمی‌توان عناصرش را تغییر داد، حذف کرد یا عنصر جدیدی به آن اضافه کرد.

---

# 1. تاپل چیست؟

تاپل در پایتون یک مجموعه **ترتیبی (Ordered)** و **تغییرناپذیر (Immutable)** از مقادیر است.

با استفاده از تاپل می‌توانیم چندین مقدار را در یک متغیر ذخیره کنیم.

برای مثال:

```python id="t8m3q6"
person = ("Ali", 25, "Tehran")
```

در این مثال سه مقدار مختلف در یک تاپل ذخیره شده‌اند.

تاپل می‌تواند شامل انواع مختلف داده باشد:

```python id="r4k7p2"
data = ("Ali", 25, 3.14, True)
```

---

# 2. ویژگی‌های تاپل

تاپل چند ویژگی مهم دارد:

### 1. ترتیبی (Ordered)

عناصر تاپل دارای ترتیب مشخص هستند و هر عنصر یک **اندیس (Index)** دارد.

### 2. تغییرناپذیر (Immutable)

بعد از ایجاد تاپل، نمی‌توان عناصر آن را تغییر داد.

### 3. امکان وجود عناصر تکراری

در یک تاپل می‌توان چند عنصر یکسان داشت:

```python id="m9v2c5"
numbers = (10, 20, 10, 30, 20)
```

---

# 3. نحوه تعریف تاپل

برای تعریف تاپل معمولاً از **پرانتز `()`** استفاده می‌کنیم.

```python id="k5q8n3"
numbers = (10, 20, 30, 40)
```

اعضای تاپل با علامت `,` از یکدیگر جدا می‌شوند.

---

# 4. ساخت تاپل خالی

برای ایجاد یک تاپل خالی می‌توانیم از پرانتز باز و بسته استفاده کنیم:

```python id="p7m4x2"
numbers = ()
```

در این حالت متغیر `numbers` یک تاپل خالی است.

همچنین می‌توانیم از تابع `tuple()` استفاده کنیم:

```python id="v3k9r6"
numbers = tuple()
```

---

# 5. تاپل تک‌عضوی

یکی از نکات مهم در تعریف تاپل این است که اگر تاپل فقط **یک عضو** داشته باشد، باید بعد از آن عضو حتماً علامت `,` قرار دهیم.

صحیح:

```python id="c8q2m5"
numbers = (10,)
```

اما این:

```python id="x4n7p1"
numbers = (10)
```

تاپل نیست؛ بلکه یک مقدار عددی معمولی است.

می‌توانیم نوع آن را بررسی کنیم:

```python id="z6r3k8"
print(type((10,)))
```

خروجی:

```text id="s2m9q4"
<class 'tuple'>
```

اما:

```python id="h5v8c2"
print(type((10)))
```

خروجی:

```text id="q7p3n6"
<class 'int'>
```

بنابراین **کاما در تاپل تک‌عضوی بسیار مهم است.**

---

# 6. دسترسی به عناصر تاپل

از آنجا که تاپل یک ساختار ترتیبی است، برای دسترسی به عناصر آن از **اندیس (Index)** استفاده می‌کنیم.

اندیس از `0` شروع می‌شود.

```python id="m4q8t2"
names = ("Ali", "Reza", "Sara")

print(names[0])
```

خروجی:

```text id="n6v2p9"
Ali
```

همچنین می‌توانیم از اندیس منفی استفاده کنیم:

```python id="r7k3c5"
print(names[-1])
```

خروجی:

```text id="b2m8q4"
Sara
```

---

# 7. برش زدن تاپل (Slicing)

عملیات **Slicing** روی تاپل نیز قابل انجام است.

ساختار کلی:

```python id="x9p4k7"
tuple[start:end]
```

مثال:

```python id="c3m6v8"
numbers = (10, 20, 30, 40, 50)

print(numbers[1:4])
```

خروجی:

```text id="q8r2n5"
(20, 30, 40)
```

در این مثال، عناصر اندیس‌های `1` تا `3` انتخاب شده‌اند.

همانند لیست، در Slicing اندیس `start` شامل می‌شود اما `end` شامل نمی‌شود.

---

# 8. تغییرناپذیر بودن تاپل (Immutable)

مهم‌ترین ویژگی تاپل، **تغییرناپذیر بودن** آن است.

یعنی بعد از ایجاد یک تاپل، نمی‌توان مقدار عناصر آن را تغییر داد.

برای مثال:

```python id="v6k2m9"
numbers = (10, 20, 30)

numbers[1] = 25
```

این کد باعث ایجاد خطا می‌شود.

بنابراین نمی‌توانیم مانند لیست بنویسیم:

```python id="p4q7c1"
numbers[0] = 100
```

---

# 9. تفاوت اصلی List و Tuple

یکی از مهم‌ترین تفاوت‌های `List` و `Tuple` در **قابل تغییر بودن** آن‌هاست.

### List:

```python id="n8m3r5"
numbers = [10, 20, 30]

numbers[0] = 100
```

این کد صحیح است، زیرا لیست `Mutable` است.

### Tuple:

```python id="t5v9k2"
numbers = (10, 20, 30)

numbers[0] = 100
```

این کد خطا ایجاد می‌کند، زیرا تاپل `Immutable` است.

بنابراین:

| ویژگی        | List | Tuple |
| ------------ | ---- | ----- |
| ترتیب        | دارد | دارد  |
| اندیس        | دارد | دارد  |
| تغییرپذیر    | بله  | خیر   |
| Slicing      | دارد | دارد  |
| عناصر تکراری | مجاز | مجاز  |
| افزودن عنصر  | دارد | ندارد |
| حذف عنصر     | دارد | ندارد |

---

# 10. اتصال دو تاپل با `+`

برای اتصال دو تاپل می‌توانیم از عملگر جمع (`+`) استفاده کنیم.

```python id="q6m2v8"
tuple1 = (10, 20)
tuple2 = (30, 40)

result = tuple1 + tuple2

print(result)
```

خروجی:

```text id="r3k7n5"
(10, 20, 30, 40)
```

**نکته:** این کار تاپل‌های قبلی را تغییر نمی‌دهد، بلکه یک تاپل جدید ایجاد می‌کند.

---

# 11. حذف عناصر تاپل

از آنجا که تاپل تغییرناپذیر است، نمی‌توانیم یک عنصر خاص را از آن حذف کنیم.

برای مثال، این کد صحیح نیست:

```python id="m8q4c2"
numbers = (10, 20, 30)

del numbers[1]
```

اما می‌توانیم **کل تاپل** را با استفاده از `del` حذف کنیم:

```python id="v5r9k3"
numbers = (10, 20, 30)

del numbers
```

بعد از اجرای این دستور، متغیر `numbers` دیگر وجود نخواهد داشت.

---

# 12. به دست آوردن اندازه تاپل با `len()`

برای به دست آوردن تعداد عناصر موجود در یک تاپل از تابع `len()` استفاده می‌کنیم.

```python id="k2m7p4"
numbers = (10, 20, 30, 40)

print(len(numbers))
```

خروجی:

```text id="c8v3n6"
4
```

---

# 13. تکرار عناصر تاپل با `*`

می‌توانیم با استفاده از عملگر ضرب (`*`) عناصر یک تاپل را چند بار تکرار کنیم.

```python id="q4n8m2"
numbers = (10, 20)

result = numbers * 3

print(result)
```

خروجی:

```text id="p7c3v9"
(10, 20, 10, 20, 10, 20)
```

در این مثال، عناصر تاپل سه بار تکرار شده‌اند.

---

# 14. بررسی وجود عنصر با `in`

برای بررسی اینکه یک مقدار در تاپل وجود دارد یا خیر، از عملگر `in` استفاده می‌کنیم.

```python id="m5r2k8"
numbers = (10, 20, 30, 40)

print(20 in numbers)
```

خروجی:

```text id="x3q7n1"
True
```

اگر مقدار مورد نظر وجود نداشته باشد:

```python id="v8m4c6"
print(50 in numbers)
```

خروجی:

```text id="s2k9p5"
False
```

همچنین می‌توانیم از `not in` استفاده کنیم:

```python id="r6n3q8"
print(50 not in numbers)
```

خروجی:

```text id="t4m7c2"
True
```

---

# جمع‌بندی

`Tuple` یکی از ساختارهای داده مهم در پایتون است که برای ذخیره چند مقدار **ترتیبی و تغییرناپذیر** استفاده می‌شود.

مهم‌ترین عملیات مربوط به تاپل:

| عملیات          | روش                |
| --------------- | ------------------ |
| ساخت تاپل       | `()`               |
| ساخت تاپل خالی  | `()` یا `tuple()`  |
| تاپل تک‌عضوی    | `(10,)`            |
| دسترسی به عنصر  | `tuple[index]`     |
| Slicing         | `tuple[start:end]` |
| اتصال دو تاپل   | `+`                |
| تکرار عناصر     | `*`                |
| تعداد عناصر     | `len()`            |
| بررسی وجود عنصر | `in`               |
| حذف کل تاپل     | `del`              |

### نکات مهم

1. تاپل **ترتیبی (Ordered)** است.
2. تاپل **تغییرناپذیر (Immutable)** است.
3. تاپل دارای **اندیس** است.
4. عملیات **Slicing** روی تاپل قابل انجام است.
5. عناصر تکراری در تاپل مجاز هستند.
6. برای ساخت تاپل تک‌عضوی باید حتماً از **کاما** استفاده کنیم:

```python
(10,)
```

7. نمی‌توان یک عنصر را به صورت مستقیم از تاپل تغییر داد یا حذف کرد.
8. می‌توان دو تاپل را با `+` به یکدیگر متصل کرد.
9. می‌توان عناصر تاپل را با `*` تکرار کرد.
10. برای بررسی وجود یک عنصر از `in` استفاده می‌کنیم.
